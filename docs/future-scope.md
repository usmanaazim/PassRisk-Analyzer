# Future scope

Documented for the academic report; not all items are implemented.

- Password manager integration (local, user-controlled)
- Enterprise password policy analysis
- Organization-level auditing using anonymized scores only
- Password breach notification through privacy-preserving methods (k-anonymity / range queries) — never bulk-upload plaintext
- Advanced ML models and transformer-based strength estimation
- Adaptive risk scoring from contextual signals (device, reuse metadata without secrets)
- Password policy compliance and enterprise reporting

Unsafe items that will not be added: credential harvesting, attacks against third-party authentication, distribution of cracking wordlists built from real leaks.
