# Data directory

This folder holds **synthetic educational word lists only**.

- `sample/common_passwords.txt` contains well-known trivial passwords used in textbooks and demos (`password`, `123456`, `qwerty`, and similar).
- Do **not** place leaked credential dumps, corporate password databases, or real user secrets here.
- The application never writes submitted passwords to this directory.

If you later add a public research dataset, document the source, license, and that it must remain uncommitted if it contains real credentials.
